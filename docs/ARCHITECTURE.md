# Архитектура Taskflow

## Общая схема

Taskflow --- клиентское веб-приложение. Интерфейс формируется из HTML,
стилизуется CSS, а поведение реализовано на JavaScript. Сборка и сервер
разработки обеспечиваются Vite.

## Основные части

-   `index.html` --- разметка интерфейса и подключение стилей и
    скриптов.
-   `main.js` --- ES-модуль с логикой задач, состоянием интерфейса,
    фильтрами, темами, датами и сохранением.
-   `public/script.js` --- классический скрипт приложения, содержащий
    реализацию основных операций со списком задач.
-   `public/features.js` --- дополнительные возможности: подзадачи,
    командная палитра и PWA-интеграция.
-   `public/voice-smart.js` --- преобразование распознанных голосовых
    фраз в команды быстрого ввода.
-   `voice-whisper.js` и `whisper-test.js` --- интеграция распознавания
    речи через Whisper WASM.
-   `public/sw.js` --- Service Worker и работа с кешем.
-   `welcome.js` / `public/welcome.js` --- логика приветственного
    интерфейса.
-   CSS-файлы --- оформление основного интерфейса, дополнительных
    функций и приветственного экрана.

## Данные

Задачи хранятся в браузерном `localStorage` под ключом `taskflow:v1`.
Данные остаются на устройстве и в профиле браузера, в котором
используется приложение. Серверная синхронизация и централизованная база
данных в текущей конфигурации не заявлены.

## Голосовой ввод

Поток голосового ввода использует разрешение браузера на доступ к
микрофону, Web Audio API и Whisper WASM. После распознавания текст может
быть обработан `TaskflowVoice` из `public/voice-smart.js`, который
добавляет маркеры приоритета и срока, понятные парсеру задач.

## Сборка

Vite собирает приложение командой `npm run build`. Результат помещается
в `dist/`. Команда `npm run preview` позволяет локально проверить
production-сборку.
