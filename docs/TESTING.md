# Тестирование Taskflow

## Unit-тесты

Запуск:

``` bash
npm test
```

Используются Vitest и jsdom. Конфигурация `vitest.config.mjs` включает
файлы `tests/unit/**/*.test.js`.

Текущий набор `tests/unit/voice-smart.test.js` проверяет четыре сценария
преобразования голосового текста:

1.  Удаление вводной команды добавления задачи.
2.  Распознавание срочного приоритета.
3.  Распознавание относительной даты «завтра».
4.  Преобразование даты с названием месяца в числовой формат.

Последний предоставленный результат: **4 теста пройдены**.

## E2E-тесты

Запуск:

``` bash
npm run test:e2e
```

Используются Playwright и Chromium. Конфигурация `playwright.config.js`
запускает Vite на `http://127.0.0.1:4173`.

Сценарий `tests/e2e/taskflow.spec.js` проверяет пользовательский путь:

1.  Очистка локального хранилища перед тестом.
2.  Добавление новой задачи.
3.  Проверка появления задачи в списке.
4.  Отметка задачи как выполненной.
5.  Удаление задачи и проверка, что она исчезла из списка.

Последний предоставленный результат: **1 E2E-тест пройден**.

## Production-сборка

Запуск:

``` bash
npm run build
```

Последний предоставленный результат: сборка Vite завершилась успешно.

В логе присутствует предупреждение о JavaScript-чанке размером примерно
1,36 МБ до gzip (около 497 КБ после gzip). Это предупреждение о размере
бандла, а не ошибка сборки.

## Воспроизведение проверок

Для повторного запуска установите зависимости:

``` bash
npm install
```

Затем выполните нужные команды из корня проекта.
