# Taskflow

Taskflow --- веб-приложение для управления личными задачами. Оно
позволяет создавать задачи, назначать приоритеты и сроки, разбивать
большие дела на подзадачи и отслеживать прогресс выполнения.

Интерфейс приложения на русском языке. Данные задач сохраняются локально
в браузере.

## Возможности

-   Создание, редактирование и удаление задач.
-   Отметка задач как выполненных и отмена удаления через уведомление.
-   Приоритеты задач: обычный, важный и срочный.
-   Сроки выполнения: сегодня, завтра, послезавтра и конкретная дата.
-   Быстрый ввод приоритетов и сроков с помощью команд в тексте задачи.
-   Подзадачи с индивидуальным статусом и индикатором прогресса.
-   Фильтрация задач: все, активные и выполненные.
-   Перетаскивание задач для изменения порядка.
-   Поиск задач и командная палитра.
-   Светлая и тёмная темы.
-   Горячие клавиши.
-   Голосовой ввод на русском языке с использованием Whisper WASM.
-   PWA-манифест и возможность установки приложения в поддерживаемых
    браузерах.
-   Локальное сохранение задач в `localStorage`.

## Технологии

-   HTML5
-   CSS3
-   JavaScript (ES modules)
-   Vite
-   Whisper WASM (`@timur00kh/whisper.wasm`)
-   Vitest и jsdom для модульных тестов
-   Playwright для E2E-тестирования
-   Web App Manifest и Service Worker для PWA-функций

## Быстрый старт

Требуется установленный Node.js и npm.

``` bash
git clone <repository-url>
cd dolist
npm install
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминал.

## Команды

  Команда                Назначение
  ---------------------- --------------------------------------
  `npm run dev`          Запуск сервера разработки
  `npm run build`        Production-сборка в `dist/`
  `npm run preview`      Локальный просмотр production-сборки
  `npm test`             Запуск модульных тестов Vitest
  `npm run test:watch`   Запуск Vitest в watch-режиме
  `npm run test:e2e`     Запуск E2E-тестов Playwright

Для E2E-тестов используется Chromium. Конфигурация Playwright запускает
Vite на `http://127.0.0.1:4173`.

## Быстрый ввод

В поле задачи можно использовать специальные маркеры приоритета и срока.
Парсер распознаёт, в частности:

  Маркер                         Значение
  ------------------------------ --------------------------------
  `!срочно`, `!urgent`, `!3`     Срочный приоритет
  `!важно`, `!important`, `!2`   Важный приоритет
  `!обычно`, `!normal`, `!1`     Обычный приоритет
  `@сегодня`, `@today`           Срок --- сегодня
  `@завтра`, `@tomorrow`         Срок --- завтра
  `@послезавтра`                 Срок --- послезавтра
  `@25.12`                       Конкретная дата (день и месяц)

Пример:

``` text
Подготовить отчёт !срочно @завтра
```

Распознанные маркеры используются как параметры задачи, а не как часть
её обычного названия.

## Голосовой ввод

Голосовой ввод использует микрофон браузера и библиотеку
`@timur00kh/whisper.wasm` для распознавания речи. Для работы необходимо
разрешить доступ к микрофону. Возможность использования микрофона и
WebAssembly зависит от браузера и условий запуска приложения.

Распознанная фраза передаётся в обработчик голосовых команд, который
преобразует формулировки вроде «добавь задачу купить молоко завтра» в
формат быстрого ввода Taskflow.

## Хранение данных

Задачи сохраняются в `localStorage` браузера под ключом `taskflow:v1`.
Это означает, что данные привязаны к конкретному браузеру и профилю
пользователя.

-   Серверная база данных не используется.
-   Автоматическая синхронизация между устройствами не предусмотрена.
-   Очистка данных сайта или хранилища браузера может привести к
    удалению сохранённых задач.

## PWA

В проекте есть Web App Manifest с названием Taskflow, русским языком
интерфейса, режимом отображения `standalone` и иконками приложения.
Проект также содержит Service Worker.

Установка и офлайн-возможности зависят от браузера, протокола и
корректной доступности ресурсов Service Worker. Для локальной разработки
используется Vite; для проверки production-версии выполните:

``` bash
npm run build
npm run preview
```

## Тестирование

Тесты разделены на два уровня:

-   **Unit:** Vitest + jsdom. Проверяется преобразование голосовых
    формулировок в команды быстрого ввода.
-   **E2E:** Playwright + Chromium. Проверяется основной
    пользовательский сценарий: создание задачи, отметка выполнения и
    удаление.

Последний предоставленный запуск тестов:

  Проверка             Результат
  -------------------- ----------------------------
  `npm test`           4 теста пройдены
  `npm run test:e2e`   1 E2E-тест пройден
  `npm run build`      Сборка завершилась успешно

При production-сборке Vite выводит предупреждение о размере одного из
JavaScript-чанков: около 1,36 МБ до gzip и 497 КБ после gzip. Это
предупреждение не мешает завершению сборки.

Подробности находятся в [`docs/TESTING.md`](docs/TESTING.md).

## Структура проекта

``` text
dolist/
├── assets/                 # Изображения и графические ресурсы
├── public/                 # Статические файлы, PWA и дополнительные скрипты
│   ├── icons/              # Иконки приложения
│   ├── features.js         # Дополнительные функции интерфейса
│   ├── script.js           # Скрипт приложения
│   ├── sw.js               # Service Worker
│   ├── voice-smart.js      # Обработка голосовых формулировок
│   └── welcome.js          # Экран приветствия
├── tests/
│   ├── e2e/                # E2E-тесты Playwright
│   └── unit/               # Unit-тесты Vitest
├── docs/                   # Документация проекта
├── index.html              # HTML-разметка приложения
├── main.js                 # Модульная точка входа
├── package.json            # Зависимости и npm-команды
├── package-lock.json       # Зафиксированные версии зависимостей
├── vite.config.mjs         # Конфигурация Vite
├── vitest.config.mjs       # Конфигурация Vitest
├── playwright.config.js    # Конфигурация Playwright
└── manifest.webmanifest    # PWA-манифест
```

В корневой папке также находятся CSS-файлы и вспомогательные файлы
голосового ввода. Список выше показывает основные элементы проекта, а не
исчерпывающий перечень.
